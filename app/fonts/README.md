# Pretendard

Pretendard Variable v1.3.9, distributed under the SIL Open Font License 1.1.
See `OFL.txt` for the original copyright and license text.

Source: https://github.com/orioncactus/pretendard/tree/v1.3.9
Original file: `packages/pretendard/dist/web/variable/woff2/PretendardVariable.woff2`

The unmodified variable font includes Korean, Latin and numeric glyphs and weights
100–900. It is served by the app through `next/font/local`; visitors do not need
to contact an external font CDN. `display: swap` keeps text visible while loading.
