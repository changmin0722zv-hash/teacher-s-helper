# 수업의 결 — 개인 수업 계획 도구

대한민국 초등학교 선생님을 위한 데스크톱 중심 수업 계획 웹앱입니다. 단원 계획을 먼저 세우고, 차시별 활동을 학반별 수업으로 구체화합니다. 여러 학년을 맡는 전담교사와 한 학급을 맡는 담임교사 모두 사용할 수 있습니다.

## 구현된 기능

- 수업 계획: 교과, 날짜, 제목, 학년·학반, 남은 일 수, 준비상태, 학습목표, 교재, 활동, 학생피드백, 참고사항, 최초 기록 날짜
- 단원 지도 계획: 단원명, 학년·교과, 성취 수준, 차시별 활동, 기본설계, 비고
- 차시는 기본 6개이며 추가·삭제 가능. 연결된 수업이 있는 차시는 연결 해제 후 삭제
- 월간·주간 달력, 준비상태 보드, 수업·단원 목록과 상세 편집
- 교과·학년·학반 필터와 검색, 다른 학반으로 수업 복제, 전체 JSON 내려받기
- 상태: 계획 중 → 자료 준비 중 → 준비 완료 → 수업 완료
- 날짜는 Asia/Seoul 기준. 교시는 사용하지 않음
- 개인 GitHub 계정만 로그인 허용. 웹과 Codex가 `data/planner.json`을 함께 사용
- GitHub 파일 SHA를 통한 충돌 감지. 충돌 시 미저장 초안을 내려받은 뒤 최신 내용을 불러올 수 있음

성취 수준은 선생님이 자유롭게 입력합니다. 교육과정 문구를 자동 생성하거나 공식 성취기준을 내장하지 않습니다. 기본설계는 요청이 없으면 빈 문자열로 남습니다. 학생피드백은 학급 전체의 반응과 다음 수업 참고사항이며 학생별 기록을 수집하지 않습니다.

## 빠르게 개발하기

Node.js 24와 npm이 필요합니다.

```bash
npm ci
LOCAL_DEMO=true npm run dev
```

데모는 로그인 없이 화면을 개발·검증하는 모드입니다. 데이터는 무시되는 `.local/planner.json`에 저장되며 GitHub에 올라가지 않습니다. 개발 서버는 루프백 인터페이스에 바인딩합니다. 운영 빌드에서는 `LOCAL_DEMO=true`여도 데모 모드가 켜지지 않습니다.

```bash
npm run validate:data
npm test
npm run build
npm run typecheck
```

브라우저 테스트는 별도 개발 서버를 자동으로 실행합니다. 먼저 직접 실행한 개발 서버를 종료하세요.

```bash
npx playwright install chromium
npm run test:e2e
# 시스템 Chromium이 있으면 다운로드 없이 사용 가능:
CHROMIUM_EXECUTABLE=/usr/bin/chromium npm run test:e2e
```

브라우저 테스트는 로컬 데모에 임시 데이터를 만들고 종료 시 기존 데이터를 복구합니다. 테스트 중에는 같은 데모를 직접 편집하지 마세요. GitHub의 실제 데이터에는 접근하지 않습니다.

## 학교·집에서 함께 쓰기

[배포 및 로그인 연결 안내](docs/DEPLOYMENT.md)를 따라 Private 저장소를 Vercel에 연결하고 GitHub OAuth App을 설정합니다. 현재 소스만으로 실제 사이트가 배포되거나 계정 연결이 완료되지는 않습니다.

Next.js 서버가 필요합니다. GitHub Pages와 같은 정적 호스팅만으로는 로그인 및 GitHub 저장 기능이 작동하지 않습니다. 별도 데이터베이스는 사용하지 않습니다. 배포 서비스의 요금·사용 한도는 해당 서비스의 현재 안내를 확인하세요.

## Codex로 입력하기

같은 Private 저장소를 연결한 Codex에 다음처럼 요청합니다.

> 10월 21일 5학년 2반 영어 수업으로 ‘길 묻기 역할극’을 추가해줘. 준비상태는 자료 준비 중, 활동은 짝과 지도 보며 길 안내하기야. GitHub main에 저장해줘.

Codex는 `AGENTS.md`와 [데이터 규칙](docs/DATA.md)을 읽고 `data/planner.json`을 수정합니다. 상대 날짜는 한국 시간을 기준으로 확정하고, 어떤 수업인지 모호하면 확인합니다. 최신 원격 데이터를 먼저 확인하고 검증 후 GitHub에 반영해야 합니다. **Codex 작업이 실제 원격 브랜치에 반영된 뒤** 웹 화면의 새로고침 버튼으로 불러옵니다. 채팅 입력 자체가 즉시 자동 동기화되는 것은 아닙니다.

화면에서는 ‘계획 저장’을 누르면 바로 GitHub 커밋이 생성됩니다. 보드에서 상태를 바꾸는 경우에도 저장됩니다. 저장 완료 메시지를 확인하고 다른 컴퓨터로 이동하세요. 두 곳에서 동시에 수정하면 자동으로 덮어쓰지 않습니다.

## 데이터와 제한

- 운영 데이터: Private 저장소의 `data/planner.json`. 변경 이력은 GitHub 커밋에 남습니다.
- 개발 데모: `.local/planner.json`. 실제 데이터와 분리됩니다.
- 첨부파일 업로드 대신 교재에 텍스트·링크를 적을 수 있습니다.
- 한 번에 저장하는 JSON의 한도는 900KB입니다. 장기간 기록이 쌓이면 학년도별 분리를 별도로 추가할 수 있습니다.
- 오프라인 저장, 자동 병합, 알림, 인쇄 전용 화면, 학생별 기록은 첫 버전에 포함되지 않습니다.
- OAuth 실제 로그인과 운영 GitHub 저장은 배포 후 본인 계정으로 검증해야 합니다. 모의 GitHub API 테스트는 실제 서비스 연결 성공을 보장하지 않습니다.

## 구성

`app/`은 페이지와 인증·저장 API, `components/`는 화면, `lib/planner.ts`는 데이터 검증과 날짜 규칙, `lib/auth.ts`·`lib/security.ts`는 인증, `lib/storage.ts`는 저장을 담당합니다. 인증 정보는 서버에서만 사용하며 `NEXT_PUBLIC_` 환경 변수나 소스에 넣지 않습니다.
